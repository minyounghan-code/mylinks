개인정보처리방침

최종 업데이트: 2026년 8월 25일

본 애플리케이션(OllIM)은 운영자 본인의 YouTube 채널에 콘텐츠를 업로드·관리하기 위한 개인용 도구입니다.

수집하는 정보

본 앱은 Google OAuth를 통해 운영자 본인의 YouTube 계정에 대한 접근 권한만을 사용하며, 제3자의 개인정보를 수집·저장·공유하지 않습니다.

정보의 사용

획득한 접근 권한은 운영자 본인 채널의 동영상 업로드, 댓글 작성, 메타데이터 관리에만 사용됩니다. Google API로부터 받은 정보는 외부에 전송되지 않으며 운영자의 로컬 환경에만 보관됩니다.

제3자 제공

어떠한 정보도 제3자에게 제공, 판매, 공유하지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

본 앱의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 준수합니다.
